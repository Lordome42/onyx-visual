# Onyx Visual (Оникс визуал)

Визуальный мод Fabric для Minecraft 26.2 на основе Glimmer 9.2.1 (CC0). Меню — ClickGUI (Right Shift).
Сборка: JDK 25, `./gradlew build` → `build/libs/onyx-visual-*.jar`.
Нужны Fabric Loader >= 0.20 и Fabric API.
Шрифты: Inter (OFL), Material Icons (Apache-2.0), см. licenses/.
